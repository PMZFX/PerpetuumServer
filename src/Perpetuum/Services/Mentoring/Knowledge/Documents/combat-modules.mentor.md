For an offensive module, first lock the intended target, select that lock, load compatible ammunition when the module requires it, and move within the module's usable range. Also check line of sight, accumulator energy, module cooldown, and whether the specific target permits the action. Locking range and weapon range are separate limits, so a valid lock does not guarantee a useful shot. A character still marked as being in onboarding/training can attack valid tutorial drones; that character state alone does not mean combat is disabled.
