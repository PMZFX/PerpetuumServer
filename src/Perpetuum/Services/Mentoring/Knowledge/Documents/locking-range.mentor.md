Locking identifies a target for your modules; select a unit and use the Lock Target action, then wait for the lock to complete. With the documented default client bindings, F locks the selected target, R locks it and makes it the primary target (or makes an existing lock primary), and U unlocks it. These bindings are customizable, so direct the player to the client keyboard settings if the defaults do not work. The same actions are available through the landmark/targeting UI. Your robot's locking range limits whether you can acquire the target, while each module has its own effective range. Optimal range is the favorable part of a weapon's envelope; performance generally becomes less reliable beyond it, so consult the current module and ammunition information for exact values.
